project (formerly `labust/labustsim-proto`). That upstream project declares the
Apache License 2.0 on its default source branch.

The absorbed copy predates the current generated Python branch and did not
retain its exact generation commit. Preserve this notice and the repository
root Apache-2.0 license when redistributing these files. Before making material
changes, obtain the intended upstream `.proto` revision, record its commit in
`external/ROS_THIRD_PARTY.md`, and regenerate the Python modules rather than
editing generated files directly.
