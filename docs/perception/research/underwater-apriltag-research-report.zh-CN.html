FinsROV 水下 AprilTag 定位调研报告

检索日期：2026-07-01。检索范围：Google Scholar、论文主页、出版社页面、arXiv、GitHub、项目文档。本文关注 AprilTag/ArUco 在水下定位时的几何误差、折射修正、开源代码，以及对当前 FinsROV ROS2 感知链路的落地方案。

核心结论：AprilTag 潜入水下以后，检测本身不一定失效，但普通 pinhole `solvePnP` 的几何模型会出现系统性偏差。偏差来源取决于相机位置：如果相机在水下平口壳体内，问题是空气-玻璃-水多层平面折射；如果相机在水面上方俯视水下 tag，问题是空气-水界面折射，而且界面固定在世界水面上，还可能有波纹。两种模型不能直接混用。

1. 对当前 FinsROV 的直接判断

你的现有链路大致是：相机检测 AprilTag PnP，水压计给 depth，IMU 给姿态，然后在 state_estimation 中融合。这个方向是对的，但水下 tag 会带来两个风险：

  • 几何偏差：普通 AprilTag PnP 假设光线在单一介质中直线传播。tag 在水下时，光线穿过水面或舱窗会折射，投影不再满足普通针孔模型。
  • 观测质量下降：水体吸收、散射、浊度、表面反光、运动模糊会降低角点稳定性。论文评估显示 AprilTag 在水下通常比 ArUco/ARToolKit 更稳，但距离、角度和浊度仍会显著影响检测质量。[1]

1.1 两种必须区分的折射场景

场景 物理模型 对 FinsROV 的含义 优先方案
相机在水下，装在平口防水壳内 空气-玻璃-水多层平面折射，折射界面相对相机固定。 CalibMar、Pinax、flat-port refractive camera model 可以直接参考。[10][11] 离线标定平口壳体参数；短期用 rectification map 后再跑 AprilTag；长期实现 refractive PnP/refinement。
相机在水面上方，俯视水下 AprilTag 空气-水单界面折射，界面通常固定在世界水面；若水面有波纹，法向随时间变化。 这是你当前固定俯视相机更可能遇到的问题。普通 PnP 的 z 和横向位置都会受深度影响。 使用水压计深度强约束；根据像素射线、水面平面和 Snell 定律修正 x/y；tag 姿态只在重投影残差小的时候使用。

1.2 推荐落地路线

阶段 目标 做法 风险
短期，1-2 天 先让实船定位可用。 保留现有 AprilTag PnP，但 position.z 只用水压计；视觉只更新 x/y 和低频 yaw；用 tag 像素尺寸、重投影误差、decision margin、视角做 gate。 仍有深度相关系统偏差；水面反光/波纹会造成跳变。
中期，1-2 周 修正水面折射导致的 x/y 偏差。 做一个“空气相机看水下点”的 refractive ray 校正：像素反投影为空气射线，和水面相交，用 Snell 定律折射到水中，再结合压力 depth 求水下点位置。用多 tag/多角点非线性优化 body pose。 需要稳定水面平面参数；水面波纹无法完全建模。
长期，研究版 高精度 6D 位姿和可解释协方差。 使用 refractive absolute pose / refractive pose refinement。单个 AprilTag 只有 4 个共面角点，建议使用多 tag board 或 3D-AprilTag 结构。[13][14] 实现复杂度高；需要 Ceres/g2o 优化和严格标定。

2. 水下 AprilTag / ArUco 定位论文

论文 方法与结论 是否处理水下折射 开源代码 对 FinsROV 的启示
An Evaluation of Artificial Fiducial Markers in Underwater Environments
dos Santos Cesar et al., OCEANS 2015。[1]		 比较 ARToolKit、AprilTags、ArUco 在不同浊度和照明下的检测距离、角度、尺寸和耗时。AprilTags 通常鲁棒性最好，但检测较慢。 未建模折射
重点是浊度、照明、散射、对比度。		 无专属代码；使用已有 ARToolKit、AprilTag、ArUco。 水下用 AprilTag 是合理选择；要把距离、角度、像素面积作为观测质量门限。
Underwater AprilTag SLAM and Calibration for High Precision Robot Localization
Westman & Kaess, CMU-RI-TR-18-43, 2018。[2]		 用 AprilTag board 实现水下高精度、无漂移 localization/SLAM，同时估计相机到车辆里程计坐标外参。 主要用水下标定吸收误差
使用针孔模型和畸变校正，未做严格 Snell 折射模型。		 未找到专属 GitHub。 对 FinsROV 最重要的是：相机-机体系外参应可标定；多个 tag 固定成板比散装单 tag 更稳定。
An Underwater Visual Navigation Method Based on Multiple ArUco Markers
Xu et al., JMSE 2021。[3]		 在水下布置多个 ArUco marker，建立单 marker 噪声模型，并做多 marker 最优融合。 未严格建模折射
文中强调水下相机标定可减小折射影响。		 未找到专属 GitHub。 适合 FinsROV：多 tag 融合比单 tag 稳定；可以把距离/角度映射到 EKF 测量协方差。
Underwater Marker-Based Pose-Estimation With Associated Uncertainty
Risholm et al., ICCVW/OceanVision 2021。[4]		 用 EfficientDet 预测 ArUco 角点，PnP 得到 6DoF，同时用 MC dropout 输出不确定度；浊度升高时误差明显变大。 未建模折射
重点是浊度和不确定度。		 未找到专属 GitHub。 状态融合层不应只接收 pose，应接收协方差或质量指标。浊水/远距/角点差时降低视觉权重。
Evaluation of Underwater AprilTag Localization for Highly Agile Micro Underwater Robots
Bauschmann et al., IROS 2023。[5]		 系统评估 AprilTag 水下定位，关注动态运动、相机选择和标定介质；结论包括水下标定很重要，精度随相机距离近似线性下降。 强调水下标定
不以折射物理模型为主。		 未找到专属 GitHub。 必须在最终介质/安装状态下标定；可以用距离-误差曲线设视觉协方差。
Towards Robust Autonomous Underwater Docking for Long-Term Under-Ice Exploration
Creutz et al., OCEANS 2023。[6]		 用 AprilTag 视觉特征、USBL、IMU、DVL、压力等做融合和 docking 状态机，201 次对接成功 194 次。 未重点建模折射
重点是融合、状态机和传感器异常处理。		 未找到专属 GitHub。 视觉丢失时必须有状态机和 fallback；不要让 EKF 因视觉失效而发散。
Visual Close-Range Navigation and Docking of Underwater Vehicles
Rannestad et al., OCEANS 2023。[7]		 使用 docking plate 上的 ArUco 标记进行单目近距导航和对接。 未找到严格折射模型 未找到专属 GitHub。 如果 FinsROV 后续做坞站/回收，tag 应作为坞站结构的一部分，而不是临时贴纸。
Relative Localization and Dynamic Tracking of Underwater Robots Based on 3D-AprilTag
Tang et al., JMSE 2025。[8]		 把多个 AprilTag 贴到 3D 结构不同面，结合距离、视角、置信度加权和切换 Kalman filter，减少视角变化带来的跳变。 未严格建模折射
处理低光、浊度、遮挡和多面 tag 切换。		 未找到专属 GitHub。 如果单个水平 tag 容易出视野或姿态退化，应改成多 tag board 或 3D tag 结构。
DeepTurbid: Underwater Marker Detection and Pose Estimation in Turbid Conditions
Meng et al., Information Fusion 2025/2026。[9]		 面向浑浊水下 marker detection 和 pose estimation 的深度模型，预测关键点和 marker ID，并用水下成像模型合成训练数据。 偏成像退化/浊度
不是几何折射 PnP 主线。		 GitHub 存在，但当前主要是占位/说明，代码可用性有限。[30] 浊度严重时，传统角点检测可能不够；但当前 FinsROV 短期不建议先上深度模型。

3. 折射相机模型与 Refractive PnP 论文

论文/工具 核心内容 适合解决什么问题 开源代码 FinsROV 适配建议
Flat Refractive Geometry
Treibitz et al., TPAMI 2012 / CVPR 2008。[10]		 说明平面折射会破坏普通单视点针孔模型，建立 flat refractive geometry。 解释为什么普通 PnP 会系统性偏。 未找到官方 GitHub。 作为理论依据，不建议直接从这篇开始写工程代码。
Refractive Calibration of Underwater Cameras
Jordt-Sedlazeck & Koch, ECCV 2012。[11]		 标定水下相机平口壳体参数，包括玻璃法向和相机-玻璃距离。 水下相机平口壳体标定。 CalibMar 实现了相关 flat-port model。[25] 如果相机以后放入水下壳体，这是首选标定方向。
The Pinax-Model for Accurate and Efficient Refraction Correction of Underwater Cameras in Flat-Pane Housings
Łuczyński et al., Ocean Engineering 2017。[12]		 工程化平口折射校正模型，用 lookup/rectification 实现高效校正。 先校正图像，再跑普通 AprilTag。 有 Pinax 代码和 CamOdoCal+Pinax Docker 工具。[26][27] 如果 camera 在平口壳体内，短期性价比高；如果 camera 在水面上方，则不能直接套用。
Absolute Pose for Cameras Under Flat Refractive Interfaces
Håner & Åström, CVPR 2015。[13]		 给出相机通过已知平面折射界面观测已知 3D 点时的 absolute pose solver。 折射版 PnP。 有 MATLAB/C++ MEX 研究代码。[28] 单个 AprilTag 只有 4 角点，对通用 refractive PnP 不稳；建议多 tag board。
Refractive Pose Refinement
Hu et al., IJCV 2023。[14]		 对 absolute/relative pose 做 refractive refinement，并区分界面固定在相机上和固定在世界中两类场景。 用普通 PnP 做初值，再做折射非线性优化。 RefractiveSfM 开源。[29] 对 FinsROV 很关键：水面上方相机属于“界面固定在世界中”的思路；水下平口壳体属于“界面固定在相机上”。
CalibMar: A Calibration Tool for Refractive Underwater Vision
Seegräber et al., 2024/2025。[15]		 开源水下折射标定工具，支持 camera/stereo/housing calibration，flat/dome port。 离线标定水下相机和壳体参数。 CalibMar GitHub/GitLab。[25] 建议作为 FinsROV 相机水下标定工具链候选。
Refractive COLMAP: Refractive Structure-from-Motion Revisited
She et al., IROS 2024。[16]		 把 flat/dome refractive camera model 集成进 COLMAP，支持 refractive SfM 和 bundle adjustment。 离线建图、外参验证、多视角折射优化。 COLMAP Underwater 开源。[24] 不适合直接上艇实时闭环，但适合离线评估和借用投影/BA 实现。
Online Refractive Camera Model Calibration in Visual Inertial Odometry
Singh & Alexis, IROS 2024。[17]		 在 VIO 状态中在线估计折射率，使空气中标定的相机可在水下使用。 水下 VIO，而不是 marker PnP。 ReAqROVIO 开源。[23] 后续如果 FinsROV 做视觉惯导，可以参考；当前 AprilTag 定位不建议先走这条。

5. 对当前 ROS2 架构的修改建议

5.1 不建议继续把普通 PnP 的 z 当真实深度

水下 AprilTag 的 T_camera_tag.position.z 可能被折射系统性拉偏。当前 FinsROV 已有水压计，应当让压力深度主导 position.z。视觉 PnP 的 z 可以作为 debug 和异常检测，不应强约束 EKF。

5.2 状态融合层应使用质量感知观测

建议 /finsrov/vision/tag_poses_3d_camera 或后续新消息增加/使用这些字段：

  • reprojection_error_px
  • decision_margin
  • tag 像素边长 / 面积
  • tag 入射角估计
  • 是否经过 refractive correction
  • 观测协方差或质量等级

5.3 如果相机在水面上方，建议实现水面折射校正节点

实现已统一放在 perception；折射约束位姿与状态融合之间仍通过 ROS2 topic 解耦：

AprilTag corner pixels
  + camera intrinsics
  + T_world_camera
  + water_plane_world: n, d
  + refractive_index_air / refractive_index_water
  + pressure depth
  + T_tag_body
  => corrected visual measurement: x, y, yaw, covariance

最小工程实现可以先只估计 tag 中心 x/y：像素中心反投影成空气射线，与水面相交，按 Snell 定律折射成水中射线，再与 z=-depth_m 平面相交。之后再扩展到四个角点的非线性 pose optimization。

5.4 如果相机改成水下相机，优先接 CalibMar/Pinax

如果后续把相机放进防水壳并浸入水中，应转向 flat-port housing 模型。短期用 CalibMar 标定 housing 参数，Pinax 或类似 rectification map 做图像校正；中长期再把 refractive projection 写进 tag pose optimizer。

6. 建议实验

实验 目的 做法 输出
深度误差曲线 量化普通 PnP 随水深偏移。 把 AprilTag 固定在已知 x/y，分别放在 0、0.2、0.4、0.6、0.8 m 深度，记录普通 PnP 和真实点差异。 error_xy(depth, image_radius) 拟合曲线。
水面扰动测试 评估波纹对视觉观测的影响。 静水、轻微扰动、推进器扰动三种状态下采集 tag pose。 视觉协方差放大规则和 reject gate。
多 tag board 测试 解决单 tag 角点少、遮挡和姿态退化。 制作一个刚性 board，上面放 3-6 个 AprilTag，已知相对位置。 多 tag 融合后的稳定性提升。
压力深度强约束融合 避免视觉 z 错误进入控制。 EKF 中只用压力更新 z，视觉只更新 x/y/yaw。 控制器输入更稳定。

7. 结论

  1. 水下 AprilTag 是可行方向，但普通 PnP 不能无条件相信，尤其是 tag 在水下、相机在水面上方时。
  2. 当前 FinsROV 最稳妥的第一版是：压力深度定 z，IMU 定姿态主频，AprilTag 提供 x/y 和低频 yaw 校正，并用质量门限控制 EKF 更新。
  3. 如果追求更高精度，需要实现折射几何：水面上方俯视用 air-water refractive ray model；水下平口相机用 flat-port multi-layer refractive camera model。
  4. 开源代码方面，直接可用的 detector 仍是 AprilTag 3；折射标定优先看 CalibMar/Pinax；refractive PnP/refinement 可参考 refractive_pose 和 RefractiveSfM，但需要工程化。
